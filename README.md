# StringManolo Web

Cybersecurity research and development website built with React + Vite.

## Features
- Minimalist, professional design
- Responsive layout
- SEO optimized
- No advertising
- Privacy-focused

## Tech Stack
- React 18
- Vite 5
- CSS-in-JS

## Getting Started

### Prerequisites
- Node.js 18+
- npm 9+

### Installation
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deployment
Deploy the `dist/` folder to your hosting.
